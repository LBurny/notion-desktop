# Notion Desktop v0.2.8 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.8) | 中文

---

**本次发布：彻底修复暗黑模式窗口白边在部分电脑上仍出现的问题（根因：PowerShell Add-Type 编译失败）。**

1. **改用 koffi 原生 FFI 直调 DWM。** 前几版用 PowerShell 的 `Add-Type` 内联编译 C# 来调 `DwmSetWindowAttribute`，但部分机器上 `Add-Type` 编译会失败（受限语言模式 CLM / 缺 csc.exe / 安全软件拦截），`[DwmApi]` 类型不存在，调用抛「找不到类型」非终止错误、返回值留空，白边一直残留。现在改用 **koffi**（N-API 预编译原生库，不依赖 .NET 编译器、不受 CLM 限制）直接从主进程调 DWM，PowerShell 链路降级为回退。

2. **DWM/主题调用写文件日志 `nd-dwm.log`**（位于 `%APPDATA%\notion-desktop\`），记录启动主题、`onApplied` 触发、DWM 属性设置结果与所用路径（koffi / powershell / pwsh），便于跨机器定位。

> 排查过程：同版本(19045)机器一台生效一台不生效，逐一排除 DWM 属性号（20→19）、系统「边框显示强调色」、主题上报时机后，用文件日志定位到——失败机器上 DWM 调用返回**空值**（`r20= r19=`），而非错误码，正是 `Add-Type` 编译失败、`[DwmApi]` 类型不存在的特征。改用 koffi 后不再依赖动态编译，从根上消除这类跨机器差异。

**测试**：新增 koffi 直调路径用例（属性 20→19 兜底、HWND 指针转换、koffi 异常回退 PowerShell），全量 **279 单测过**。
