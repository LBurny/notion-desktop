# Notion Desktop v0.2.8 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.8) | 中文

---

**本次发布的重点：修复暗黑模式窗口白边在部分电脑上仍出现的问题（第二层根因：PowerShell 版本）。**

1. **修复：DWM 调用自动回退 PowerShell 7。** 前几版用 `powershell.exe`（Windows PowerShell 5.1）通过 `Add-Type` 内联编译 C# 来调 DWM 深色属性。但部分机器上 5.1 跑 `Add-Type` 会闪退/失败，属性永远设不上去，白边一直残留——而这台机器的 PowerShell 7（`pwsh`）正常。现在应用**先试 5.1，失败（无结果）自动回退 pwsh 7**，覆盖两种环境。日志 `[dwm]` 行带来源 shell，便于确认走了哪条。

> 排查过程：同版本(19045)机器一台生效一台不生效，逐一排除了 DWM 属性号（20→19）、系统「边框显示强调色」、主题上报时机（v0.2.7 已修）后，最终用读回属性值确认——应用把窗口属性留在了浅色(0)，根源是 in-app 调用 `powershell.exe` 5.1 在部分机器上 Add-Type 编译 C# 会失败。

**测试**：新增 shell 回退链用例（5.1 失败回退 pwsh / 成功不回退 / 全失败汇总），全量 **273 单测过**。
