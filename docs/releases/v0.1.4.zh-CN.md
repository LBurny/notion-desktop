# Notion Desktop v0.1.4 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.4) | 中文

---

**本次发布的重点：标题栏排版与字体优化，样式/设置子窗口圆角真正生效。**

**界面优化**：

- 样式/设置子窗口改为透明窗口 + 4px 圆角（与托盘右键菜单同款）。注：上一轮的圆角尝试被 CSS 背景传播规则抵消（body 背景按整窗矩形绘制，顶掉 border-radius），本次改为内层容器绘制背景与圆角，像素级验证四角真正透明
- 标题栏按钮族宽度统一为 36px（侧栏开关、新建标签按钮原本各不相同）
- 标题栏右侧 Share/收藏/更多 与 最小化/最大化/关闭 之间新增竖分隔线（随主题变色），功能区分组更清晰
- 最大化按钮字形收窄（□ 同字号下视觉偏大），标题栏字体/图标/按钮整体微调

下载附件 **Notion.Desktop.Setup.0.1.4.exe**（NSIS 安装器，可选安装目录）。
