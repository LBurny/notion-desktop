# Notion Desktop v0.1.12 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.12) | 中文

---

**本次发布的重点：公式默认字体改为 Times New Roman；修复行内公式不跟随公式字体设置、仍显示正文字体的问题；修复斜杠快捷键删除某一条时其余新增项被连带删除的问题。**

**公式默认字体改为 Times New Roman**：

- 公式槽留空（使用内置默认）时，默认字体由 Modern 系数学字体改为 Times New Roman——与正文拉丁字体保持一致，外观更统一
- Times New Roman 是 Windows 几乎必装的字体，绝大多数机器开箱即生效；未安装时才回落到本机已装的 Modern 系数学字体（Latin Modern Math / Modern Math / Modern 等，按名称模糊匹配）
- Times New Roman 与 Modern 系都没装时，仍交给 default.css 的 KaTeX_Main 默认栈兜底
- 回退栈与已选字体自动去重，避免 Times New Roman 在字体链中重复出现

**行内公式字体修复**：

- 修复行内公式（inline math）不跟随公式字体设置、仍显示正文字体的问题——此前仅展示公式（块级公式）生效
- 根因：行内公式的 CSS 选择器只覆盖了 `.notion-text-block`（段落块），标题、列表、引用、Callout 等块里的行内公式不匹配，落回正文字体
- 现新增通用行内公式选择器覆盖所有块类型，同时保留 `.notion-text-block` 专项高特异性选择器以压过 custom.css 旧副本

**斜杠快捷键删除连带清除修复**：

- 修复在设置页斜杠快捷键列表中连续添加多条后，删除其中一条时其余新增项被一并清除的问题
- 根因：新增行在用户填入命令前都是草稿（命令为空、不提交主进程），且共用同一占位组合键；删除触发提交后主进程回播刷新，草稿合并按组合键去重时把同键的其余草稿误删
- 现草稿只与已提交项去重，草稿之间不再互相去重，多条新增行在改键/填命令前均能保留
