# Notion Desktop v0.1.7 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.7) | 中文

---

**本次发布的重点：公式默认字体改为 Modern 系（按已装字体名模糊匹配）；暗色模式下数字调节钮等系统控件跟随主题；设置窗口内容可滚动；修复托盘菜单打开样式/设置时主窗口被连带弹出的问题；两个子窗口布局与风格统一。**

**公式字体**：

- 公式槽留空时的内置默认从 KaTeX_Main 改为本机已装的 Modern 系数学字体：同一字体在不同机器安装名不一（Latin Modern Math / Modern Math / Latin Modern Roman / Modern 等），按注册表枚举到的已装字体名模糊匹配；完全未装 Modern 系的机器维持 KaTeX_Main 现状不变
- 公式字体输入框的占位提示会显示本机实际解析出的默认字体名（如「默认：Modern (All res)」）
- 修正匹配规则误中 Cambria Math 的问题（Cambria Math 是 Windows 必装的非 Modern 系数学字体，只看 math 关键词会让所有 Windows 机器的默认公式字体都解析成它；现在必须名字含 modern 才算 Modern 系）

**暗色模式**：

- 行间距等数字输入框的上下调节钮、滚动条等系统原生控件在暗色主题下渲染为深色（此前是刺眼白底）

**设置/样式子窗口**：

- 设置窗口内容区可滚动：斜杠命令快捷键添加较多时，底部的「关闭窗口时」等区块滚轮可达（此前窗口尺寸固定，加多了直接看不到）
- 样式窗口同样改为可滚动兜底，以后新增设置项不必再调整窗口基准高度
- 两个子窗口统一为 400px 宽（设置窗不再偏窄），样式页新增「字体 / 版式 / 其他」分区，与设置页同风格
- 托盘菜单打开「样式」「设置」时不再连带弹出主窗口（主窗口最小化到托盘时只出现子窗口）；托盘菜单「打开主界面」行为不变

**附**：两页共享样式抽为单一事实源（`shared/base-win.css`），子页面设计规范已沉淀进 AGENTS.md，后续新增设置子页面有统一模板。

下载附件 **Notion.Desktop.Setup.0.1.7.exe**（NSIS 安装器，可选安装目录）。
