# Notion Desktop v0.2.5 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.5) | 中文

---

**本次发布的重点：新建/关闭标签页快捷键可配置 + 修复新建标签页设置样式不生效。**

1. **新增：标签快捷键可配置。** 之前「新建标签页（Ctrl+T）/ 关闭标签页（Ctrl+W）」是硬编码，现在设置页「快捷键」分区新增这两项，可改成任意组合键（改键后旧键即失效，浏览器同义键 Ctrl+Tab / PageDown / 数字位仍照常可用）。
2. **修复：新建标签页设置样式不生效。** 预热视图在认领为标签页时立即移除旧 key 并重注最新 CSS，并注册 `dom-ready` 兜底重注（覆盖整页重载清空 author CSS 的情况），SPA 跳转到位后再次重注压过新页异步 CSS——确保新页面的字体/主题等设置一定生效。
3. **优化：子窗口高度统一。** 设置页默认高度由 595 调整为与样式页一致的 585，两窗口滚动行为一致（`#form` 共享滚动样式）。
4. **优化：斜杠命令「+ 新添加快捷键」按钮样式。** 虚线按钮改为与上方命令框对齐（左对齐首个快捷键框、右对齐命令框）、文字居中，布局更规整。

**测试**：新增/更新标签快捷键配置、CSS 重注相关回归单测，全量 **260 单测过**。

下载附件 **Notion.Desktop.Setup.0.2.5.exe**（NSIS 安装器，可选安装目录）。
