# Notion Desktop v0.1.13 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.13) | 中文

---

**本次发布的重点：修复代码块字体不生效——代码体仍显示正文字体、仅语言标签（Python/JSON 等）跟随代码字体的问题。**

**代码块字体修复**：

- 修复设置代码字体后，代码块正文仍显示正文字体、只有右上角语言标签（Python、JSON 等）生效的问题
- 根因：代码正文位于 `div[contenteditable="true"]` 内，被正文规则 `.notion-page-block div[contenteditable="true"] *` 以特异性 (0,2,1) 命中；而代码块选择器只到 `.notion-code-block *` (0,1,0) / `.notion-code-block code` (0,1,1)，特异性不足，代码体被正文字体压过——语言标签不在 contenteditable 内故不受影响、仍正常显示等宽字体
- 现新增 `.notion-code-block div[contenteditable="true"] *` 镜像选择器（同特异性 0,2,1，设置 CSS 最后注入者赢），代码正文稳定落到代码字体；浮层预览（Quick Find 等）里的代码块同样补齐
