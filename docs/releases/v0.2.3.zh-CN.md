# Notion Desktop v0.2.3 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.3) | 中文

---

**本次发布的重点：修复 Ctrl+T 新建标签时主进程崩溃（`newTabInteractive is not defined`）。**

**问题**：`before-input-event` 里 Ctrl+T 走的 `new-tab` 动作裸调了未定义的 `newTabInteractive`（应为 `flow.newTabInteractive`），导致 Ctrl+T 报错崩溃。+ 按钮走 IPC 不受影响，所以 v0.2.2 冒烟时只测了 + 没发现。该 bug 自 v0.1.15 起就存在，本次一并修复。

**修复**：改为 `flow.newTabInteractive()`，并加 Ctrl+T 回归单测（红绿验证）。全量 255 单测通过。

⚠️ v0.2.2 用 Ctrl+T 会崩溃，请升级到 v0.2.3。

下载附件 **Notion.Desktop.Setup.0.2.3.exe**（NSIS 安装器，可选安装目录）。
