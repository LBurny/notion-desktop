# Notion Desktop v0.2.9 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.9) | 中文

---

**本次发布：确认暗黑模式白边修复生效，并清理已废弃的 PowerShell 代码。**

1. **白边修复确认稳定。** v0.2.8 改用 koffi 原生 FFI 直调 DWM 后，暗黑模式窗口白边在出问题的机器上已确认消失（日志从 `nd-dwm fail r20= r19= via powershell` 变为 `nd-dwm ok attr=20 via koffi`）。

2. **移除冗余的 PowerShell 调用链路。** 早期用 PowerShell `Add-Type` 内联编译 C# 调 DWM，但部分机器上 `Add-Type` 编译失败导致白边残留，现已彻底弃用。本版删除了整套 PowerShell 回退代码（`buildScript` / `parseStatus` / `tryShells` / `hwndToLong`）以及调试期间加的 `nd-dwm.log` 文件日志，`window-dark-mode.js` 精简为纯 koffi 直调。

**测试**：精简后的 koffi 路径用例全量 **通过**。
