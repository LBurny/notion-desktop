# Notion Desktop v0.1.6 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.6) | 中文

---

**本次发布的重点：修复「正文字体改了真正文字不变」的 bug；界面字体与正文字体解耦（控制条/侧栏/浮层不再跟随正文）；样式设置窗加宽并贴合内容。**

**字体修复**：

- 修复正文字体设置只作用于目录、条目编号等容器，真正的正文文字不变的问题（实测根因：`.notion-page-content *` 选中器特殊性只有 (0,1,0)，压不过 Custom CSS 旧副本里直接命中文字叶节点的 `[contenteditable="true"]:first-of-type`(0,2,0) 规则；设置字体规则现改为完整镜像旧版全局字体表的选择器，保证正文文字必然跟随设置）
- 界面字体（页签、Share 按钮、侧栏、面包屑、Quick Find 等浮层）改为独立槽位：留空时回落界面内置默认栈，不再跟随正文。系统标题栏本身也改为跟随界面字体槽（标题栏的页签/按钮属界面而非正文）
- 旧版设置的全局字体（顶层 `font` 字段）迁移时同时写入正文与界面槽，存量用户升级后界面字体不会跳变；之后修改正文字体不再牵动界面

**样式设置窗**：

- 样式窗加宽至 400px（正文字体等长输入行不再局促），高度贴合表单内容，屏蔽右下角帮助按钮选项下方不再空出一大段留白
- 设置窗口尺寸支持各子页面独立配置宽/高（仍随页面缩放等比放大）

**附**：cdp-fonts-check 端到端验证脚本新增「真实正文文字叶节点」断言，防止以后出现探针全绿但真实文字未变的假绿。
