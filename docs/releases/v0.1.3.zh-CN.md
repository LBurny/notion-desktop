# Notion Desktop v0.1.3 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.3) | 中文

---

**本次发布的重点：框架整体提速与结构整理，以及一批此前已就绪的功能与修复。**

**提速**：

- 启动加速：启用 V8 编译缓存（加速模块编译），并新增 `ND_PERF=1` 环境变量输出启动/加载里程碑耗时，便于后续量化对比
- 设置/样式子窗口关闭后改为隐藏缓存（原为销毁重建），重开即时显示
- Quick Find 选中结果后：原来固定等待 150ms 再切换标签，改为探针轮询浮层关闭后立即执行（典型 30~60ms，探针不通时仍走原节奏兜底）
- 切换到非活动标签时顶栏分享/收藏按钮状态立即刷新（原为 300ms 防抖后才探测）
- 缩放快捷键连续微调时落盘防抖合并；注入 CSS 合并结果进程内缓存（custom.css 变更仍即时重载）
- 后台标签关闭 Chromium 节流（backgroundThrottling=false），切回标签不再有重绘顿挫

**功能与修复**：

- 主题持久化（theme.json）：启动时即知上次主题，深色主题下不再出现启动白标题栏/白加载页；适配"深色任务栏 + 浅色应用"的混合模式系统
- Quick Find 时序修复：选中搜索结果后来源页浮层正常关闭（焦点回输入框 + 延迟摘除视图）
- 标题栏字体跟随页面实际生效的计算 font-family（含 custom.css 与设置注入的效果），不再只读设置字段

**架构整理（便于后续维护）**：

- index.js 由 385 行总装配瘦身为装配层；拆出 theme-service / settings-windows / hotkey-service 独立模块
- tabs.js 拆出 Quick Find 待命状态机（quick-find-flow.js）与顶栏中继（topbar-relay.js），标签页文件专注视图生命周期
- preload 探针函数由 `scripts/build-preload-probes.js` 从 topbar-actions.js 生成（单一事实源，`npm run sync-probes` 随时重新生成，测试自动校验同步），消除手工镜像两份代码的风险
- 新逻辑全部配套 node:test 单测（共 161 个，全部通过）
