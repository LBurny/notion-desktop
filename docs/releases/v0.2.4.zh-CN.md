# Notion Desktop v0.2.4 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.4) | 中文

---

**本次发布的重点：修复切换标签时偶发崩溃「Can't add a destroyed child view」。**

**根因**：预热视图的 `dom-ready`/`did-finish-load`/`did-fail-load` 处理器在认领后仍挂在已变成标签页的 webContents 上。该标签页后续若发生主帧加载失败（如兜底整页加载失败），残留的 `did-fail-load` 会 `wc.close()` 销毁标签视图；之后切回该标签，`attachActive` 的 `addChildView` 拿到已销毁视图即崩溃。

**修复（两层）**：

1. **根因**：预热视图处理器加 `v !== view` 闸口——认领后该视图不再是当前预热视图，残留处理器即变 no-op，不再误注入 CSS / 误改预热状态 / 误销毁标签视图。
2. **防御**：`ensureView` 检测到 `rec.view.webContents.isDestroyed()` 时置空重建，`addChildView` 永远拿不到已销毁视图。

**测试**：新增「认领后残留 did-fail-load 不销毁视图」「活动视图已销毁则重建」两个回归单测，全量 **257 单测过**。

⚠️ v0.2.3 切换标签会偶发崩溃，请升级到 v0.2.4。
