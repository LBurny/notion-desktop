# Notion Desktop v0.1.8 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.1.8) | 中文

---

**本次发布的重点：壳界面（设置/样式/标题栏/托盘菜单）支持中英文切换，默认跟随系统语言；新增开机静默启动——登录 Windows 后自动驻留托盘、不弹主窗口，全局快捷键开箱即用。**

**中英文切换**：

- 设置页新增「语言」分区：跟随系统（默认）/ 中文 / English 三选一
- 跟随系统时：系统语言为中文则用中文界面，其余语言（含英文及任何其他语言）一律用英文
- 覆盖全部壳界面：设置、样式两个子窗口的完整文案，标题栏的页签关闭提示与按钮悬停文本，托盘菜单条目
- 切换即时生效，无需重启；样式页的字体占位提示（如「默认：Modern (All res)」）等动态内容同样跟随

**开机静默启动**：

- 设置页新增「启动」分区，勾选「开机静默启动」后，登录 Windows 时应用自动启动并驻留托盘，不弹出主窗口
- 静默启动后全局快捷键（呼出窗口、缩放等）立即可用，需要界面时托盘菜单「打开主界面」或快捷键呼出即可
- 从开始菜单 / 桌面图标手动打开时主窗口照常显示，不受该选项影响
- 仅对安装版生效（注册表登录项由安装版写入），开发模式运行不受影响

**设置窗口**：

- 默认高度 440 → 595，容纳新增的「启动」「语言」两个分区，常用选项免滚动

下载附件 **Notion.Desktop.Setup.0.1.8.exe**（NSIS 安装器，可选安装目录）。
