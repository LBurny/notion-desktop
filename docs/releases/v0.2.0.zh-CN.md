# Notion Desktop v0.2.0 更新说明

[English](https://github.com/LBurny/notion-desktop/releases/tag/v0.2.0) | 中文

---

**本次发布的重点：大幅优化页面加载与侧栏响应速度——点「+」进入新页面、在新标签点 ☰ 展开侧栏，从秒级冷加载降到瞬时/百毫秒级。**

**常驻「预热视图」——点「+」进新页面秒开**：

- 此前每开一个新标签都会冷加载整个 Notion 网页应用（实测 ~4.6s），是「点 + 选结果后等很久页面才出来」的根因
- 现在后台常驻一个已加载 Notion 首页的隐藏视图；新标签直接认领它，经 Notion 自身客户端路由（注入隐藏链接并点击）瞬时跳到目标页，不再冷加载整个 SPA
- 兜底无回归：预热未就绪时回退原冷加载路径；个别 URL 若走整页加载而非 SPA 内导航，1.5s 内自动 `loadURL` 兜底
- 首标签加载完才预热，不抢启动带宽；认领后后台重建，下一个新标签同样秒开；主题/CSS 变化与退出时正确同步/销毁

**侧栏 ☰ 响应提速（双管齐下）**：

- 认领的预热视图在首页时侧栏按钮早已挂载，新标签点 ☰ 即点即应，根本不进重试循环——这是 ☰ 在新标签上「点了没反应、等一会才出现」的主因
- 对仍走冷加载的标签（如启动时的活动标签），重试退避间隔由 `250→450→650ms` 收紧到 `50→70→130ms…`，按钮一挂载就尽快补点，把等待从秒级压到百毫秒级

**测试与端到端**：

- 新增预热视图状态机单测、`spaNavigate` 探针单测、`ensureView` 认领预热路径回归，全量 255 项单测通过
- e2e 脚本（cdp-tabs-check / cdp-sidebar-check）适配预热视图：按标题栏活动标签标题精确选中活动页，避免误选后台预热视图；新增新标签 SPA 内导航路径的只读观察
